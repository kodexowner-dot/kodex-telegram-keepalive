# KODEX Telegram Keepalive

Автоматический запуск команды `/start` в вашем Telegram-боте каждые 5 минут через GitHub Actions.

## Важно

- Используйте только собственный второй Telegram-аккаунт и собственного бота.
- GitHub Actions запускает задачу по расписанию, но время старта может задерживаться; это не гарантия пробуждения Render.
- Не публикуйте Telegram-код входа, пароль 2FA или строку сессии. Секреты добавляются только в GitHub Actions Secrets.
- Повторные `/start` будут создавать сообщения в чате с ботом.

## Настройка

Следуйте разделу **Setup** после добавления файлов проекта.
